# Demo video script (2–3 minutes)

1. **Intro (15 sec):** “This is Campusly, a college event dashboard built for student clubs. It demonstrates a responsive frontend, REST API, database, and performance estimate feature.”
2. **Dashboard (25 sec):** Show the overview cards, involvement chart, recent activity, and responsive layout.
3. **Event interactions (30 sec):** Search events, switch to Explore events and My registrations, register for an event, and add a sample event. Mention that these actions in the standalone UI are demo-session state.
4. **Predictor (30 sec):** Enter attendance, previous marks, study hours, and assignment completion. Explain that the current score is a transparent illustrative baseline, not a validated ML model.
5. **Backend API (45 sec):** Open `http://127.0.0.1:8000/docs`; show GET `/api/events`, POST `/api/events`, POST `/api/predict`, and `/api/stats`.
6. **Wrap-up (15 sec):** Explain technologies: HTML/CSS/JavaScript, Python FastAPI, SQLite, GitHub, and intended cloud deployment.

Before recording, start the API and test each endpoint. Keep the browser zoom at 90–100%, hide personal tabs, and record in 1080p if available.
